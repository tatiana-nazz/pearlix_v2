# Phase 13F.1 QA

## Scope

Admin-controlled clinic default shifts, Doctor and Staff working shifts, versioned leave, split-shift availability, and explicit Doctor appointment-impact confirmation.

## API and Role Checks

- Admin manages clinic defaults, employee shifts, applying defaults, copying schedules, and leave cancellation.
- Staff and Doctor can read only their own generic working shifts; Staff retains the Doctor working-hours read route required for appointment booking.
- Staff and Doctor own schedule and leave routes are read-only. No shift or leave Delete action is exposed.
- `MISSING_ONLY` preserves existing shifts and skips conflicts or exact duplicates. `REPLACE_ALL` deactivates old shifts and creates independent copies.
- Default template updates never silently propagate to employees.

## Scheduling Checks

- Weekday `0` is Monday. Multiple active split shifts are allowed; adjacent shifts are valid; active overlaps and overnight/inverted times are rejected.
- Doctor changes that would invalidate future `UPCOMING` or `CHECKED_IN` appointments return `SHIFT_CHANGE_REQUIRES_CONFIRMATION` before mutation.
- Confirming marks each affected appointment as `NEEDS_RESCHEDULE` with `SHIFT_CHANGE` source metadata. Staff shift changes never affect appointments.
- Appointment availability remains backend-authoritative at `GET /api/appointments/availability/`; split-shift gaps do not create slots.
- Leave changes use versions and cancellation is a void operation. Doctor leave can mark appointments; Staff leave is visibility-only.

## Version Conflict Checks

- Update, activate, deactivate, and leave cancel operations require a version.
- Missing versions return `VERSION_REQUIRED`; stale versions return `VERSION_CONFLICT` with submitted and current versions.
- The frontend keeps a conflict banner open for impact confirmation and does not optimistically mutate schedules.

## Responsive Checks

- Weekly boards use 150px minimum columns and horizontal scrolling at tablet sizes.
- Forms collapse to one column at tablet width. Browser checks at 1440px, 1280px, 1024px, and 768px remain pending.
