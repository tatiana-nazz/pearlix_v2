# Phase 14C.0 QA — Team Contract Foundation

Phase 14C.0 adds no runtime Team route, sidebar item, shell, Lucide dependency, or visual redesign. Browser QA for the final Team and Users & Access screens remains Phase 14D/14F work.

Contract checks cover Admin-only Team API access, transactional Doctor/Staff onboarding, paged linked-profile results, optimistic profile update/status operations, generic orphan/role-PATCH protection, signed role transition preflight/confirmation, history blocks, reactivation, and audit sanitization.

Frontend contract wrappers are `src/api/endpoints/team.ts` and `src/types/team.ts`; they match the actual serializers and expose no runtime route. Run `npm run typecheck`, `npm run test:run`, and `npm run build` before handoff.
